КОСТЯ 33 — локальный сайт-подарок

Запуск без установки:
1. Откройте файл index.html двойным щелчком.
2. Для звуков интерфейса нажмите SFX: OFF в левом верхнем углу.

Рекомендуемый запуск через локальный сервер (если установлен Python):
  python -m http.server 4173
Затем откройте http://localhost:4173

Сайт работает без сборки, интернета и платных зависимостей.
